# 🌐 前端登录注册静态网站（支持 GitHub Pages 部署）

纯原生 HTML + CSS + JavaScript，**无后端、零依赖**，可直接部署到 GitHub Pages，实现主页、登录页、注册页整套前端登录模拟。

## 📁 项目目录结构

## ✨ 项目功能

- ✅ 页面分离：首页 / 登录 / 注册 3个页面，统一UI风格
- ✅ 公共样式抽离：`common.css` 统一管理所有页面样式
- ✅ 公共JS抽离：新增 `common.js`，封装**退出登录**公共方法，所有页面可调用
- ✅ 前端模拟账号系统：账号信息存储在浏览器 `localStorage`
- ✅ 注册校验：非空校验 + 两次密码比对 + 用户名查重
- ✅ 登录校验：核对用户名密码，登录状态本地保存
- ✅ 退出登录：一键清除登录状态，返回首页
- ✅ 响应式布局：电脑、手机端自适应展示
- ✅ 现代化UI：圆角卡片、阴影、hover过渡动画
- ✅ 静态托管：无需后端，支持 GitHub Pages 直接部署

## 🚀 GitHub Pages 部署教程

1. 在 GitHub 创建**公开仓库**，仓库命名格式：`你的用户名.github.io`
2. 将项目全部文件上传到仓库**根目录**
3. 打开仓库 `Settings` → 找到 `Pages`
4. Build and deployment：Source 选择 `Deploy from a branch`，分支选择 `main`，文件夹选择 `/root`
5. 等待 1~3 分钟部署完成，访问地址：`https://你的用户名.github.io`

## 💻 本地运行

直接双击 `index.html` 在浏览器打开，**无需安装任何软件、不需要编译**。

## 📄 技术栈

- HTML5：搭建页面结构
- CSS3：全局样式、卡片、动画、移动端适配
- JavaScript：表单校验、本地存储、登录状态、公共退出登录功能

> ⚠️ 重要说明：仅前端模拟登录，数据保存在浏览器本地存储。清除浏览器缓存/无痕模式会丢失账号，**无法跨设备同步账号，没有后端数据库**。
