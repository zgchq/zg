🌐 个人静态主页（GitHub Pages）
这是一个基于 HTML + CSS + JavaScript 开发的极简静态网页，无后端、无依赖，可直接托管部署在 GitHub Pages。
📁 项目结构
项目采用前端标准分离结构，代码清晰易维护：
./
├── index.html # 页面主体结构
├── style.css # 全部样式文件
├── script.js # 交互逻辑脚本
└── README.md # 项目说明文档
✨ 页面功能

- 纯静态部署：无需服务器，GitHub Pages 直接托管
- 实时时间展示：JS 动态刷新本地时间
- 交互按钮：点击切换页面文本内容
- 自适应样式：电脑/手机端均可正常显示
- 现代化UI：圆角、阴影、hover 动效
  🚀 部署教程（GitHub Pages）

1. 新建 GitHub 公开仓库，仓库名必须为：用户名.github.io
2. 将所有文件上传至仓库 根目录
3. 进入仓库 Settings → Pages
4. 部署来源选择：main分支 + /root
5. 等待 1-3 分钟，访问链接：https://用户名.github.io
   💻 本地运行
   直接双击 index.html 即可打开页面，无需任何编译环境。
   📄 技术栈

- HTML5：页面结构搭建
- CSS3：页面样式、动画、适配
- JavaScript：页面交互、动态数据处理
